# Repository instructions

The templates exist to demonstrate how to use the Pubky SDK and provide clear, reusable functions that developers can build on. Keep the UI focused on exercising those functions. Judge additions by the SDK capability or useful pattern they teach; avoid separate application features that repeat an existing example or imply concepts the SDK does not have.

For Pubky SDK upgrades, SDK Dependabot PRs, or checks that the templates follow the latest SDK practices, use [the pubky-sdk-upgrade skill](.agents/skills/pubky-sdk-upgrade/SKILL.md). Review feature coverage, deprecations, and recommended patterns as well as the dependency version.
